# Abrham Wondimu - Portfolio

One-page developer portfolio built with HTML, CSS, Bootstrap 5.3 and a little vanilla JavaScript.

Features dark/light themes, scroll-reveal animations, a filterable project grid and a contact form that opens your email app.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
uv run --no-project python -m http.server 5501
```
